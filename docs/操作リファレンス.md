## 割り当ての変え方

設定画面の〔操作〕タブで変更します。設定画面は次のいずれかで開きます。

- メニューの〔オプション〕→「設定...」
- 既定のキー割り当て <kbd>F2</kbd>
- **Windows** — `suzunia-settings.exe` を直接実行 (別アプリです)
- **macOS** — メニューバーの〔オプション〕から (アプリに内蔵)

割り当ては 1 つのコマンドに複数のキーを与えられます (既定でも「次のページへ」に
<kbd>PageDown</kbd> と <kbd>Space</kbd> の 2 つが割り当てられています)。

## 既定のマウス割り当て

| 操作 | コマンド |
|---|---|
| 左クリック | 次のページへ |
| 右クリック | 前のページへ |
| ホイール下 | 次のページへ |
| ホイール上 | 前のページへ |
| 中クリック | 全画面表示 |
| サイドボタン 1 | 1ページ進む |
| サイドボタン 2 | 次のページへ |

**左クリックは押した位置から動かさずに離したときだけ実行されます。**
左ドラッグは表示位置のスライド (パン) と兼用なので、一定距離を超えて動かすと
クリックは取り消されてパンになります。この都合で、左クリックによるページ送りは
ボタンを離した時点で実行されます。

右・中・サイドボタンは押した時点で実行されます。ただし右ボタンに長押しか
「押しながらホイール」を割り当てている場合は、区別のため離すまで待ちます。

## メニュー構成

見出しは 6 つです。**Windows 版と macOS 版で同じ構成・同じ並び**にしてあります。

| 見出し | 主な項目 |
|---|---|
| ファイル | 開く / ファイルの再読み込み / 最近使ったファイル / しおりセーブ / しおりロード / ページをコピー / ファイル名をクリップボードへ / ページを保存 / ファイルの削除 / エクスプローラ (Finder) で開く / 他のアプリで開く (Windows のみ) / インストール先フォルダを開く / 設定ファイル保存先フォルダを開く / バージョン情報 / 終了 |
| 表示 | 表示サイズ / 背景 / チャンネルピッカー / ICC プロファイルを適用 / 全画面表示 / 情報パネル / ページスライダー / 常に手前に表示 |
| エフェクト | エフェクトプリセット 10 通りから選択 (変更済みのものには「（変更あり）」が付きます) |
| 移動 | 次/前のページ / 1ページ単位 / 設定 A・B ページ単位 / 最初・最後 / ページ番号を指定 / ランダム / 前後・ランダムな書籍 / ページ送り開始 / 終端での動作 |
| ページ | 1・2ページ表示 / 横長ページを分割 / 各種の単独表示 / サイズ調整 / 余白を自動でカット / 右開き・左開き / 並び順 / 回転 / サブフォルダを読み込む / ページ設定をリセット |
| オプション | 設定 / 設定の再読み込み |

macOS 版で違うのは 4 点だけです。

- 先頭にアプリメニューが入り、「バージョン情報」と「終了」はそちらにあります
- ページスライダーの項目はありません
- 「他のアプリで開く」はありません (Finder の「このアプリケーションで開く」があるため)
- 「最大化」「しまう」が〔表示〕の末尾にあります (Windows ではウインドウのボタン)

**〔ページ〕メニューの項目は、その本を開いている間だけの一時的な変更です。**
本を開き直すと設定ファイルの値に戻り、そのうえで
[ファイル名による指定](#ファイル名による指定)が重なります。

## 設定画面

タブは Windows 9 枚、macOS 7 枚 (他アプリとシェル統合が無い) です。項目の並びは両者で同じです。

| タブ | 設定できる群 |
|---|---|
| 表示 | ページ / 表示サイズ / 背景 / カラーマネジメント / ズーム / パン / ページ移動量 |
| エフェクト | プリセット / リサイズフィルター / アンシャープマスク / 自動レベル補正 / 疑似カラー化 / アップスケーリング (Windows のみ) / 共有設定 |
| 動作 | 起動 / 自動ページ送り / ページ移動 / 画像フォルダ / アーカイブ / ファイル操作 / ページスライダー (Windows のみ) |
| 操作 | キー割り当て / マウス割り当て |
| 他アプリ | 「他のアプリで開く」9 項目 (**Windows のみ**) |
| 性能 | プリセット / 先読みとキャッシュ / PDF (Windows のみ) / EPUB (Windows のみ) / 書庫 (rar / 7z) |
| 履歴 | 履歴 / 効果音 / ログ |
| しおり | 16 スロットの内容 |
| シェル統合 | 右クリックメニュー / ファイルの関連付け (**Windows のみ**) |

- **［エフェクト］タブの内容は、いちばん下の「共有設定」を除いて、
  「編集するプリセット」で選んだ 1 つぶんの設定です。**設定画面を開いたときは、
  **ビューア本体がそのとき使っているプリセットが選ばれた状態で始まります**
  (どれを使うかは〔エフェクト〕メニューかキー割り当てで切り替えます。
  設定画面からは変えられません)。
- **「共有設定」はプリセットで切り替わりません。**次の 2 つが入っています。
  - **設定A / 設定B** — 「エフェクト: AとBを切り替える」コマンドで行き来する 2 つ
  - **白黒・カラーの判定** — 自動レベル補正と疑似カラー化で共通のしきい値。
    しきい値を変えると両方の掛かり方が変わります。「このページはカラーか」を
    見分けるための値で、蔵書のスキャンの素性によって決まるものなので、
    プリセットごとではなく全体で 1 組だけ持ちます
- **先読みとキャッシュ**を増やすとページ送りは速くなりますが、そのぶんメモリを使います。
  大判 (1ページ 100MB 級) の本を読むときは注意してください。

## 他のアプリで開く

**Windows のみ**の機能です。表示中のファイルを画像編集ソフトなどへ渡します。
設定画面の［他アプリ］タブで **9 個まで**登録でき、1 項目につき次の 4 つを指定します。

| 項目 | 内容 |
|---|---|
| メニュー名 | 〔ファイル〕→「他のアプリで開く」に出る名前。既定は空 |
| 実行ファイルのフルパス | 「選択…」から選べます。.exe のほか .bat やショートカット (.lnk) も可。既定は空 |
| 引数 | 下の表を参照。既定は「現在のファイルパス」 |
| 起動後 | 何もしない (既定) / 最小化 / 最大化 / 終了 |

| 引数 | 渡すもの |
|---|---|
| 現在のファイルパス | 「エクスプローラで開く」と同じファイル (書庫は書庫ファイル自体、画像フォルダは表示中の画像) |
| 現在のフォルダパス | 上のファイルが入っているフォルダ |
| 画像をクリップボードへコピー | 表示中のページを原寸でクリップボードへ置いてから、引数無しで起動します (貼り付けは起動したアプリ側で行ってください) |
| 何も送らない | 引数無しで起動します |

- **メニューに出るのは、メニュー名と実行ファイルの両方を入れた項目だけ**です。
  1 つも登録していないときは「(未設定)」とだけ出ます。
- キーやマウスには「他のアプリで開く 1」〜「9」として割り当てられます
  (番号は［他アプリ］タブの行の番号です)。

## ファイル名による指定

ファイル名 (またはフォルダ名) に次のタグを含めておくと、その本を開いたときだけ
表示設定が上書きされます。

| タグ | 効果 |
|---|---|
| `[左開き]` | 左開き (1ページ目が左) で表示 |
| `[単ページ]` | 1ページ表示にする |
| `[1ページ目単独]` | 2ページ表示でも最初のページを単独表示 |
| `[最終ページ単独]` | 2ページ表示でも最後のページを単独表示 |

例: `作品名 第1巻 [左開き][1ページ目単独].zip`

開いた後にメニューで変更した場合は、そちらが優先されます。

## 設定ファイルを直接編集する

`suzunia.json` を手で編集しても構いません。反映は「設定の再読み込み」(<kbd>F5</kbd>)
か再起動です。キーとマウスの割り当ては、それぞれ次の形で入っています。

```json
{
  "keys":  { "Ctrl+Right": "NextPageSingle", "F11": "ToggleFullScreen" },
  "mouse": { "LeftClick": "NextPage", "RightGestureUp": "FirstPage" }
}
```

右側に書くのは[コマンド一覧](#コマンド一覧)の内部名です
(設定画面の〔操作〕タブに出る名前ではありません)。内部名は英語表示に切り替えると
そのまま確認できます。**綴りを間違えた行は黙って無視される**ので、
効かないときは綴りを疑ってください。

保存先は Windows が exe と同じフォルダ、macOS が
`~/Library/Application Support/suzunia/` です。
